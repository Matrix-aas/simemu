# Конфигурация стенда (bench build): автомобиль из независимых узлов

Дата: 2026-11-02. Код: `crates/simemu-physics/src/bench_config.rs` (данные, сборка plant, совместимость),
`crates/simemu-cli/src/studio/bench_build.rs` (запуск стенда, `/api/build`, сохранённые сборки, переменные окружения),
`crates/simemu-cli/src/studio/assets/build.js` (страница «Конфигурация стенда»).

## 1. Принципы

- Требование стенда: двигатель не привязан к прошивке; на стенде выбираются двигатель, турбина IS12/IS20/IS38 и
  доработки (впуск, выпуск, интеркулер, свечи, топливо, износ), навесное (форсунки DI/MPI, ТНВД, впускной
  коллектор, дроссель, катализатор), пробег мотора и каждого узла, КПП, кузов, атмосфера.
- Загрузка образа не меняет сборку; сборка не выбирает образ.
- Совместимость прошивки и сборки — только предупреждения (§5), ничего не блокируется: так ведёт себя настоящий
  автомобиль с «чужой» прошивкой.
- Только физика: каждая опция — набор физических параметров с источником; значения без паспортных данных —
  `UNVERIFIED` (константы в `bench_config.rs`, ручки калибровки модели).
- `BenchConfig::resolve` — чистая функция, вызывается один раз при запуске стенда (нулевая стоимость в шаге). Профили
  строятся из существующих конструкторов `EngineProfile`/`DrivetrainProfile` через `..base`, поэтому поля, которые
  добавляют другие работы (топливная система, детонация/вестгейт/фазовращатели), получают свои значения по умолчанию.
- Новое в plant: `EngineProfile.gas_path: GasPathHw` (`profiles.rs`) — бывшие константы `AIR_FILTER_K`,
  `EXHAUST_SYSTEM_K` стали полями (сток = прежние значения), плюс доля воздуха из моторного отсека на входе
  компрессора (подогрев) и Δp тракта наддува относительно стока. `engine.rs` читает их (5 строк). Сток
  воспроизводит прежний plant бит-в-бит (тест `baseline_reproduces_the_historical_default_plant`).

## 2. Использование

- Studio: раздел «Конфигурация стенда» (клавиша `B`, значок ⛭ в шапке). Правки сразу проверяются и
  «подготавливаются» (staged); физическая модель пересоздаётся при запуске стенда — кнопка «Запустить стенд с этой
  сборкой», «Холодный старт» или «Перезагрузка ЭБУ и ТКУ». Каждый запуск пишется в журнал сессии (сборка целиком
  в JSON, stderr сервера, метка в регистраторе). ТКУ-плата есть только при DQ200 (других прошивок КПП нет); иначе
  стенд переводится на моторный тормоз.
- Пробег: у двигателя свой, у каждого узла (форсунки DI/MPI, свечи, турбина, ТНВД, катализатор, сцепления) — свой;
  0 у узла = пробег двигателя (§3.3, износ).
- Пресеты: `octavia_fl` (базовый 1.8 TSI сток по умолчанию, §4), `a3_8v_quattro`, `golf7_gti`, `golf7r`. Сохранённые сборки — JSON в
  `~/.simemu/builds/` (или `SIMEMU_BUILDS_DIR`); недостающие поля берутся из `octavia_fl`.
- Сценарии и CLI: `SIMEMU_BUILD=<пресет|путь.json>`, затем `SIMEMU_ENGINE=cjsa|cjxc|chhb`,
  `SIMEMU_TURBO=is12|is20|is38` — для `engine_start_scenario`, `render-audio`, `replay` (заменяет
  `--profile`) и любой `StudioSession::new`.
- API: `GET /api/build`; `POST /api/build` `{action: stage|preset|discard|save|load|delete|start, build?, preset?, name?}`.

## 5. Совместимость прошивки и сборки (`bench_config::compatibility`)

Читается из образа: номер детали и строка двигателя в шапке CAL (`8V0906259J`, `2.0l R4 TFSI`, CAL+0x6C),
`c_dpl`/`c_eng_vol`, фит форсунки по `ip_ti_4_l` (как для профилей plant), `c_n_tcha_max_sp`. Номер → коды двигателя
и сток-турбина: таблица из `AGENTS.md` §3 (ETKA не проверялся). Предупреждения: объём (модель воздуха), коды двигателя,
форсунка (подача ×q_стенд/q_прошивка), турбина (сток калибровки vs стенд), защита по оборотам ротора выше предела
турбины (напр. 400 000 об/мин в тюнинг-калибровках), КПП без прошивки. Пример: S50 (`264K` / `259J`) на `octavia_fl` — «калибровка для CJXC (2.0), стоит
CJSA (1.8) — модель воздуха прошивки не соответствует двигателю», форсунка ×0.74, наддув под IS38.

## 6. Ещё не используется физикой (`PendingPhysics`)

Калильное число и материал электродов свечи (модель температуры свечи и предвоспламенения), нагар (горячие точки;
сейчас только ε), LHV/AFR/теплота испарения смеси (`cylinder.rs` — константы; работа по топливной системе), MPI,
ёмкость O₂ катализатора по пробегу (`lambda_sensor` — константа), передаточная функция и положение датчика детонации, двухступенчатый AVS, актуатор вестгейта (работа по
детонации/наддуву), подшипники турбины. Акустика (`simemu-acoustics/src/synth.rs`) берёт сопротивление фильтра из
`AIR_FILTER_K`, а не из сборки.

## 7. Открытые вопросы калибровки физической модели

- Усиленный интеркулер 60 мм: паспортные размеры сердцевины и теплоотдача (ε-NTU).
- Впуск с фильтром нулевого сопротивления: коэффициент потерь давления и доля подкапотного воздуха по скорости набегающего потока.
- Коэффициенты износа по пробегу (`WearRates`): кольца/нагар, форсунки, свечи, КПД турбины, накладки сцеплений, ёмкость катализатора.
- ТНВД: номер детали на CJSA и CJXC (`c_mfp_max` 1.8 — 150/174.5 мг против 232 мг у S50).
- ETKA: полная таблица кодов двигателей для номеров ЭБУ `8V0906264H/J/K/F`.
